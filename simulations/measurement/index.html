Educational model — not real model behaviour

Measurement simulator: watch the apparent improvement swing

Simulated Contoso tickets whose true effect you set. Change the sample size, the size mix, who chooses the agent, and add a blocked ticket — then compare what a naive analysis reports with the pre-registered one from 13.5 (log hours, stratified by size, bootstrap interval, permutation test).

Parameters

Ticket hours are drawn from a log-normal model: geometric means of 5, 16 and 47 hours for S, M and L tickets, a within-size spread you set, and a true agent effect you set. Intervals use 1,000 bootstrap resamples and 1,000 permutations (the lab tool uses 10,000), so they wobble slightly between runs. Real teams have more structure — developers, learning, versions — than this model.
