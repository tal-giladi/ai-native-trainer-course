Security simulator: which layer stops the injection?

A conceptual model of the Module 9 security-lab. Six attacks (A01–A06) each travel untrusted source → MCP / ingest → agent context → tool call → sink. Toggle defenses and watch which stage stops each trial, how many other layers would still catch it, and what residual rate you can honestly claim. No attack content is modelled — only where each path is cut.

Trace one trial

    Probabilities are invented for teaching: an undefended agent acts on injected text in about 9 of 10 trials, and a prompt-only rule lowers that to about 5–6 in 10 — never to zero (09.2). Deterministic layers either cover a path or do not. Real attacks, models and configurations behave differently; measure yours with the lab.
