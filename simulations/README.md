# Simulations

Standalone educational simulations (plain HTML, CSS and classic scripts; no network). Each opens from `file://` or in a sandboxed iframe; pass `?preset=<name>` to start at a preset and `&seed=<n>` to fix the random seed. Shared code lives in `common/`.

- [Agent loop](agent-loop/index.html) — Module 2: [02.4](../lessons/module-02/lesson-04.md), [02.5](../lessons/module-02/lesson-05.md). Presets: `happy-path` (default), `failure-classes`; also `malformed`, `toolfail`, `loop`, `escape`.
- [Context budget](context-budget/index.html) — Module 4: [04.1](../lessons/module-04/lesson-01.md), [04.3](../lessons/module-04/lesson-03.md). Presets: `bloated-rules` (default), `irrelevant-docs`.
- [Evaluation](evaluation/index.html) — Module 7: [07.3](../lessons/module-07/lesson-03.md), [07.4](../lessons/module-07/lesson-04.md), [07.5](../lessons/module-07/lesson-05.md). Presets: `biased-judge` (default), `one-run`, `paired`.
- [Security](security/index.html) — Module 9: [09.6](../lessons/module-09/lesson-06.md) (also illustrates 09.1–09.5). Presets: `baseline` (default), `prompt-only`, `layered`, `partial`, `fail-open`.
- [Multi-agent](multi-agent/index.html) — Module 10: [10.1](../lessons/module-10/lesson-01.md), [10.3](../lessons/module-10/lesson-03.md), [10.4](../lessons/module-10/lesson-04.md). Presets: `topologies`, `compounding`, `review-loop` (default); optional `&task=qa`.
- [Measurement](measurement/index.html) — Module 13: [13.3](../lessons/module-13/lesson-03.md), [13.4](../lessons/module-13/lesson-04.md), [13.5](../lessons/module-13/lesson-05.md), [13.6](../lessons/module-13/lesson-06.md). Presets: `randomized` (default), `difficulty-mix`, `selection-bias`, `outliers`, `sample-size`.
