Multi-agent simulator: reliability, cost and latency

Planner, worker and reviewer as numbers: success probabilities, reviewer recall and false alarms, cost and seconds per call. The expected values use the same equations as AgentTeam estimate (10.3); the simulated runs draw tasks one by one so you can see the spread and read traces.

Parameters

All inputs are illustrative, not measurements. The model assumes the reviewer's misses are independent of the worker's mistakes; a reviewer on the same model with the same context shares blind spots, so its real recall on the errors that matter is lower. Replace every number with your own from traces and EvalHarness stats.
