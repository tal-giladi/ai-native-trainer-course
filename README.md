# AI-Native Trainer: From Coding-Agent Power-User to Paid SDLC Trainer

A practitioner-first course that turns an experienced .NET engineer who already uses coding agents daily into the person engineering organizations pay to design, secure, evaluate, measure, teach and deliver AI-native software development — with an original, evidence-backed method and a real delivered engagement at the end.

## Who this is for

A senior software engineer or technical leader who uses coding agents daily and is comfortable with GitHub, APIs, Docker, cloud, architecture and security concepts. The course never teaches programming, Git, Docker or HTTP.

> [!NOTE]
> C#/.NET and SQL Server are needed only for the hands-on labs, which run on a small .NET + SQL Server practice app with C# checking tools. You can learn the full course — every lesson, quiz, simulation and the teaching, consulting and business modules — without them. It does teach LLM mechanics, context engineering, evaluation of stochastic systems, agent security, experimental design, instructional design, change management, consulting and sales.

## Shape of the course

- 11 stages · 22 modules · 101 lessons · ~26 hours of instruction · ~75–100 hours of labs, projects and field work over ~6–9 months part-time.
- Progression: use agents → systematize → integrate → evaluate → measure → develop a methodology → teach → sell → deliver → productize.
- Every lesson runs the loop **Learn → See → Do → Break → Diagnose → Fix → Verify → Reflect**, ends with a knowledge check, and every module ships a portfolio artifact.
- Nine portfolio repositories (see [projects](projects/README.md)), six [simulations](simulations/README.md), a [template library](templates/README.md) and a [capstone](assessments/capstone.md).

Start with the [course map](COURSE-MAP.md), then [Module 1](lessons/module-01/lesson-01.md).

## Prerequisite environment

Docker Desktop; a GitHub account with Actions; API access to at least two model providers; one coding agent (Claude Code primary) plus access to at least one of Cursor, GitHub Copilot or a Codex-class agent; a Jira/Confluence-class (or Linear/Notion-class) workspace — free tiers are enough; a real brownfield repository you may legally work on.

## Principles

Practitioner before teacher · evidence before price · own it, don't resell it · tool-agnostic core, tool-specific labs · real reps · honest limits · security, confidentiality and employer IP are first-class · every module ships an artifact.
