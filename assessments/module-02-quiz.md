# Module 2 quiz — LLM and Agent Fundamentals

Ten scenario questions that test reasoning, not recall. Each one describes a situation you will meet on a real team — a flaky ticket, a Hebrew ticket budget, a contradicting README, a runaway agent loop, a model choice under a legal constraint — and asks what is actually going on or what to do first.

**Pass mark:** 70% (7 of 10). Unlimited retries; the correct answer and an explanation appear after you submit.

**What it covers**

- Tokens, attention and effective vs nominal context — [02.1 From text to next token](../lessons/module-02/lesson-01.md)
- Softmax, temperature, top-p, compounding and retry probability — [02.2 Sampling and (non-)determinism](../lessons/module-02/lesson-02.md)
- Instruction channels, trained precedence, persuasion vs enforcement — [02.3 The instruction hierarchy](../lessons/module-02/lesson-03.md)
- The tool loop, harness-side validation and authorization, token growth — [02.4 Tool calling and the agent loop](../lessons/module-02/lesson-04.md)
- Failure classes, cost per successful task, constraints before weights — [02.5 Failure taxonomy and model selection](../lessons/module-02/lesson-05.md)

If you score below 70%, reread the lesson named in each missed question's explanation, then rerun the matching lab break before retrying.
