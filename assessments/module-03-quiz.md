# Module 3 quiz — Anatomy of an AI-Native Codebase: The AI Layer

Nine scenario questions on treating agent instructions as an engineering artifact. They test reasoning, not recall: most describe a situation in a real .NET / SQL Server team and ask what is going wrong or what you would do next.

**Covers**

- [03.1 · The fourth citizen: AI behavior as an engineering artifact](../lessons/module-03/lesson-01.md) — versioning, review with CODEOWNERS, testing, ownership, change management.
- [03.2 · Component map and portability](../lessons/module-03/lesson-02.md) — load timing, advise vs enforce, scope; AGENTS.md as the single source across tools.
- [03.3 · The brownfield audit](../lessons/module-03/lesson-03.md) — five passes, the evidence ladder, the inference filter and $p^k$.
- [03.4 · Writing a grounded rules file](../lessons/module-03/lesson-04.md) — directive, scope, evidence; lint and probes; diagnosing stale rules.

**Pass mark:** 70% (7 of 9). Unlimited retries; answers and explanations appear after you submit.

Before you start, it helps to have done the labs in [`labs/module-03`](../labs/module-03/README.md) — several questions use the Contoso Billing repository.
