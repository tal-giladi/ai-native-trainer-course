# Module 5 quiz — Research → Plan → Implement → Validate

Nine scenario questions on running a disciplined agent loop on a brownfield .NET / SQL Server codebase. They test reasoning, not recall: most describe a ticket, an artifact or a gate result and ask which phase failed, what to check next, or what to change.

**Covers**

- [05.1 · Research discipline](../lessons/module-05/lesson-01.md) — the three blind spots of paste-and-go; reuse, constraints, blast radius, open questions; read-only delegated exploration.
- [05.2 · Plans worth reviewing](../lessons/module-05/lesson-02.md) — seven criteria, boundaries as a contract, HUMAN checkpoints and stop rules, plan-lint and scope.
- [05.3 · Validation gates and reset decisions](../lessons/module-05/lesson-03.md) — the gate ladder, independence from self-report, test-integrity checks, reset versus continue.
- [05.4 · Failure diagnosis across the loop](../lessons/module-05/lesson-04.md) — origin and escape phases, escape probability across gates, the six-ticket comparison.

**Pass mark:** 70% (7 of 9). Unlimited retries; answers and explanations appear after you submit.

Before you start, it helps to have done the labs in [`labs/module-05`](../labs/module-05/README.md) — several questions use Contoso Billing and its tickets.
