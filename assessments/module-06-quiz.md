# Module 6 quiz — Skills, Sub-Agents and Workflow Automation

Nine scenario questions on designing, chaining, delegating and testing skills and sub-agents in a brownfield .NET / SQL Server repository. They test reasoning, not recall: most describe a skill, an agent, a test result or a failure and ask what is wrong, what to build, or what to check next.

**Covers**

- [06.1 · Skill anatomy](../lessons/module-06/lesson-01.md) — trigger, inputs, output contract, steps; deterministic versus model steps; descriptions; context cost.
- [06.2 · The five core skills](../lessons/module-06/lesson-02.md) — prime, spec, plan-feature, validate, pr-review; handoff through files; invocation by side effects.
- [06.3 · Sub-agents, and when not to build one](../lessons/module-06/lesson-03.md) — what isolation buys, the four questions, the delegation contract, context saved versus tokens spent.
- [06.4 · Testing, versioning and failure analysis for skills](../lessons/module-06/lesson-04.md) — four test levels, trigger recall and precision, representative ticket sets, SemVer, trigger versus context versus contract.

**Pass mark:** 70% (7 of 9). Unlimited retries; answers and explanations appear after you submit.

Before you start, it helps to have done the labs in [`labs/module-06`](../labs/module-06/README.md) — several questions use Contoso Billing, its tickets and the skills built there.
