# Module 4 quiz — Context Engineering

Nine scenario questions on context as a budget and a design problem. They test reasoning, not recall: most describe an agent misbehaving in a .NET / SQL Server repository and ask what is going on, where a fact belongs, or what a measurement actually shows.

**Covers**

- [04.1 · What context is and what it costs](../lessons/module-04/lesson-01.md) — $B = W - S - R - T - H - O$, cost of re-sending the always-loaded layer, nominal vs effective context.
- [04.2 · Layering context](../lessons/module-04/lesson-02.md) — always / on demand / generated / never; triggers, pointers, decision before trigger.
- [04.3 · Context pathologies](../lessons/module-04/lesson-03.md) — pollution, staleness, contradiction, redundancy, irrelevance, and their symptoms.
- [04.4 · Compression and compaction](../lessons/module-04/lesson-04.md) — what survives `/compact`, compact instructions, handoff notes, clear vs compact.
- [04.5 · The context audit](../lessons/module-04/lesson-05.md) — four buckets, before/after on a fixed task set, ablation, cost per passing answer.

**Pass mark:** 70% (7 of 9). Unlimited retries; answers and explanations appear after you submit.

Before you start, it helps to have done the project in [`labs/module-04`](../labs/module-04/README.md) — several questions use the Contoso Billing context layer and the tasks-v0 task set.
