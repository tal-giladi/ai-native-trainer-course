# Instructor notes — 15.3 The unedited recording and the stranger test

**Teaching objective.** Students produce one genuinely unedited 15–20 minute run with an annotated timeline that passes `DemoCheck timeline`, act on its off-script prompts and silent gaps, and run one stranger test by the protocol, turning grouped stuck points into AI-layer changes with regression checks.

**Likely confusion.** "The timeline is extra paperwork." It is what turns a video you will never rewatch into data: durations per segment for the run sheet (15.4), and a list of the moments you steered. Second: students think the stranger test measures the stranger. It measures the repository; say so in the brief.

**Common misconception.** "A hint is not help." Every hint is a stuck point fixed by the owner instead of the layer. Second: "If the final run was correct, a little editing is fine." The edit removes exactly the failures and nudges the audience needs to calibrate their trust, and it spoils the clip as a fallback.

**Key analogy.** A usability lab with a one-way mirror. The designer behind the glass may not tap on it, however painful it is to watch someone miss the button. The pain is the data.

**Common failure in the exercise.** Recording in segments "to save time", or pausing during waits. Insist on one take. Second: writing the stranger timeline from memory the same evening; it always has fewer stuck points than the recording. Third: fixing stuck points with README paragraphs nobody reads — push for changes in tool output where the stranger was looking.

**Expected exercise outcome.** `recordings/run-01-timeline.tsv` passing, or failing with a clear list of changes; a stranger timeline with verdict computed by the tool, a component table, and 2–4 changelog entries with checks. Many students fail the first stranger test; that is the expected, useful outcome. For the break: both artifacts re-judged honestly — the recording fails as "unedited", the stranger test fails at the first help.

**Extension exercise.** Run the stranger test in a different agent tool (Cursor or Copilot) using the portability work from 03.2. Which stuck points are tool-specific and which are layer-specific? What does that tell you about claims of portability in your workshop?

**Discussion question.** Your stranger got stuck because they did not know what a "research brief" is. Is that a flaw in the layer, in your method's vocabulary (Module 14), or in the stranger? How would you decide, and what would you change?
