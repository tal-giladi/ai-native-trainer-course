# Module 12 plan — Enterprise AI-Agent Architecture

5 lessons · ~80 min instruction · ~5 h practice · depends on Module 2 (02.5 hard constraints and cost per successful task), Module 7 (EvalHarness pass rates, Wilson intervals, regression gate), Module 8 (MCP credentials and the three permission layers, audit hook "ship it somewhere append-only"), Module 9 (trifecta, hardened config, `security-review-checklist.md`, residual risk) and Module 11 (headless agents, operating agents, `governance-policy.md`; written in parallel, linked by manifest path).

Thesis: an enterprise does not buy "an AI coding tool"; it runs a platform whose boxes are hosting, a gateway, identities, stores and tools, and whose every arrow must answer three questions from security and legal: whose authority, where does the data go, who can see it afterwards. The student designs that platform for a hypothetical 400-developer company (Fabrikam), breaks it the way real drafts break, and defends it with ADRs and evidence.

Shared lab: `labs/module-12/` (no Docker, no API key). `tools/ArchCheck` (dependency-free C#): `hosting`, `simulate`, `chargeback`, `lint`, `redact`, `adr`, `review`. `fabrikam/` brief, hosting options, prices, August usage, 30-question security review. `break/` the v0 draft (architecture, shared-key gateway, prompt log with fake secrets, ADRs, review answers). `solution/` v1 (architecture, per-team gateway, September usage, seven ADRs, diagram, review answers). `scripts/generate_usage.py` regenerates the usage data.
