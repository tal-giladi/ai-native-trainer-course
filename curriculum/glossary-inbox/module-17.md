- **Workshop arc** — The six-part sequence of a hands-on workshop: credibility, problem, live before/after, exercise, Q&A, close, each with a job it owes the room (lessons/module-17/lesson-01.md)
- **Show-do block** — A short live segment (at most about ten minutes) immediately followed by learners doing the same step on a sibling ticket, then a debrief from what they produced (lessons/module-17/lesson-01.md)
- **Sibling ticket** — A hands-on ticket in the same repository and AI layer as the demo ticket, exercising the same step on a different case, so that learners transfer rather than copy (lessons/module-17/lesson-01.md)
- **Cut order** — The pre-written order in which agenda steps are shortened when a workshop runs late: show steps first, never hands-on, the reflection or the post-test (lessons/module-17/lesson-01.md)
- **Starter pack** — The repository and scripts learners receive before a workshop: the code at a starting tag, a setup check, an offline package path, a no-agent path and catch-up tags (lessons/module-17/lesson-02.md)
- **Setup check** — A script learners run days before a workshop that verifies their environment and prints troubleshooting IDs instead of advice (lessons/module-17/lesson-02.md)
- **Catch-up tag** — A git tag holding the finished state of a hands-on step, so a learner who falls behind can join the next step with everyone else (lessons/module-17/lesson-02.md)
- **Paper path** — A way to do every exercise from saved agent output on a handout, for learners without agent access (lessons/module-17/lesson-02.md)
- **Question bank** — A set of rehearsed one-minute answers to predictable hard questions, each with a concession, evidence, a boundary, what is not known and a bridge back to the agenda (lessons/module-17/lesson-03.md)
- **Drift decomposition** — Splitting a rehearsal's timing error into the controlled part (talk and live steps) and the estimated part (hands-on steps), because the two can cancel in the total (lessons/module-17/lesson-04.md)
- **Deliberate practice** — Practice designed to improve specific aspects of performance, with feedback, as opposed to repetition (Ericsson et al.) (lessons/module-17/lesson-04.md)
- **Observer agreement** — How closely two independent observers' rubric scores match (exact and within one point); a difference of two points signals an anchor read differently (lessons/module-17/lesson-04.md)
- **Exit standard** — The readiness criteria for a workshop, written before the first rehearsal and judged on the last one (lessons/module-17/lesson-04.md)
