- **Paste-and-go** — Giving a coding agent only the ticket text and accepting its change without a research or planning phase; on brownfield code it tends to produce locally plausible but globally wrong changes (lessons/module-05/lesson-01.md)
- **Research brief** — A short, evidence-backed summary produced by a read-only research pass before planning: code to reuse, architecture constraints, blast radius and open questions (lessons/module-05/lesson-01.md)
- **Blast radius** — Everything that calls, reads or depends on the code a change will modify: callers, tests, schema, configuration (lessons/module-05/lesson-01.md)
- **Research → plan → implement → validate loop** — The course's working name for a phased agentic workflow in which each phase leaves a reviewable artifact and a gate; students later name their own version (lessons/module-05/lesson-01.md)
- **Plan boundaries** — The Touch and Do not touch lists in an implementation plan that make the resulting diff predictable and checkable by a scope gate (lessons/module-05/lesson-02.md)
- **Human checkpoint** — A named point in a plan where a person must approve a specific decision before the agent proceeds, usually paired with a stop rule (lessons/module-05/lesson-02.md)
- **Stop rule** — A plan rule such as "if the same step fails twice, stop and report", which turns an agent that would loop into one that asks (lessons/module-05/lesson-02.md)
- **Validation gate** — A deterministic check (build, tests, architecture rules, SQL checks, scope) that runs on an agent change regardless of the agent's own report (lessons/module-05/lesson-03.md)
- **Stop hook** — A Claude Code hook that runs when the agent tries to end its turn and can block the stop (exit code 2) until a check passes (lessons/module-05/lesson-03.md)
- **Test-integrity check** — A gate that fails on skipped tests or on fewer tests than before, protecting the test suite as an oracle from being weakened (lessons/module-05/lesson-03.md)
- **Reset (session)** — Abandoning a polluted agent session and restarting from the plan, the brief and a short learned note instead of the transcript (lessons/module-05/lesson-03.md)
- **Origin phase** — The loop phase in which a defect's wrong belief first entered an artifact (lessons/module-05/lesson-04.md)
- **Escape phase** — A later checkpoint or gate that could have caught a defect and did not (lessons/module-05/lesson-04.md)
- **Escape probability** — The chance a defect passes a series of gates, $\prod_i (1 - c_i)$ for independent catch rates $c_i$ (lessons/module-05/lesson-04.md)
