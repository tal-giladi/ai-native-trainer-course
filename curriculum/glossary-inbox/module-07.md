- **Evaluation (agent eval)** — A repeatable measurement of how often an agent system (AI layer + agent harness + model) completes a fixed set of tasks, used to decide whether a change helped (lessons/module-07/lesson-01.md)
- **Task** — One test in an evaluation: an input, a starting environment, a pass criterion and a grader (lessons/module-07/lesson-01.md)
- **Trial** — One attempt at a task in a fresh session; tasks are run several times because agent output varies (lessons/module-07/lesson-01.md)
- **Transcript** — The full record of a trial: messages, tool calls and results (lessons/module-07/lesson-01.md)
- **Outcome** — The state of the environment at the end of a trial (files changed, tests passing), as opposed to what the agent said (lessons/module-07/lesson-01.md)
- **Evaluation harness** — The infrastructure that runs tasks, records trials, grades them and aggregates results; distinct from the agent harness being evaluated (lessons/module-07/lesson-01.md)
- **Capability eval / regression eval** — A suite that measures what an agent cannot yet do reliably (low pass rate) versus one that guards what it already does (pass rate near 100%) (lessons/module-07/lesson-01.md)
- **Golden task** — A task for behavior that must never regress, checked individually by the gate rather than averaged (lessons/module-07/lesson-02.md)
- **Regression task** — A task written from a real failure or incident so that the failure cannot silently return (lessons/module-07/lesson-02.md)
- **Holdout split** — Tasks run for their score only and never used to tune the system, so a growing gap to the dev split reveals overfitting or leakage (lessons/module-07/lesson-02.md)
- **Benchmark contamination** — Benchmark tasks or solutions present in a model's training data, so the score partly measures memory (lessons/module-07/lesson-02.md)
- **Answer leakage** — Task prompts or expected answers copied into the AI layer, so the eval measures reading an answer key rather than competence (lessons/module-07/lesson-02.md)
- **Grader** — The logic that scores a trial: an outcome check, a deterministic text check, a rubric applied by a model, or a human (lessons/module-07/lesson-03.md)
- **LLM-as-judge** — Using a language model with a rubric to grade open-ended answers; needs calibration against human labels because of verbosity, position and self-preference biases (lessons/module-07/lesson-03.md)
- **Grader calibration** — Measuring a grader's precision, recall and false-positive rate against human labels before trusting its verdicts (lessons/module-07/lesson-03.md)
- **Verbosity bias** — The tendency of LLM judges to rate longer answers higher regardless of correctness (lessons/module-07/lesson-03.md)
- **Wilson interval** — A confidence interval for a proportion that stays reliable at small sample sizes and at rates near 0 or 1 (lessons/module-07/lesson-04.md)
- **pass@k** — The probability that at least one of k attempts succeeds; appropriate when a verifier picks the successful attempt (lessons/module-07/lesson-04.md)
- **pass^k** — The probability that all k attempts succeed; the reliability metric for unattended agents (lessons/module-07/lesson-04.md)
- **Pseudo-replication** — Treating repeated trials of the same few tasks as independent observations, which makes intervals far too narrow (lessons/module-07/lesson-04.md)
- **Task-clustered interval** — An interval computed from per-task pass rates, treating the task as the unit of sampling (lessons/module-07/lesson-04.md)
- **Paired design** — Comparing two configurations on the same tasks and analysing per-task differences, so task difficulty cancels (lessons/module-07/lesson-05.md)
- **A/A test** — Running the same configuration twice to check that the evaluation setup itself produces no difference (lessons/module-07/lesson-05.md)
- **Interleaving** — Alternating the arms of a comparison in rounds so that slow drift affects both equally (lessons/module-07/lesson-05.md)
- **Regression gate (eval gate)** — A CI check that blocks an AI-layer change unless the evaluation is comparable, golden tasks stay above their floors, the aggregate shows no meaningful regression and cost stays within a ceiling (lessons/module-07/lesson-06.md)
- **Baseline (eval)** — A committed, pinned, full-suite result that candidate changes are gated against; regenerated when the agent version or model changes (lessons/module-07/lesson-06.md)
