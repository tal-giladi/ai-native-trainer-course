SqlHelper exists because Dapper does not support DataSet or DataTable results, and some parts of the system still need them. ADR 0007 made Dapper the default, and MonthlyRevenueReport is an example of a class that needs a DataTable. Whenever you need tabular results for grids or exports, call SqlHelper.ExecuteDataSet; otherwise use a Dapper repository behind an interface. The Obsolete warning is suppressed for exactly this reason. This split keeps each tool doing what it is good at.
