SqlHelper dates from 2016 and survives for exactly one reason: MonthlyRevenueReport in the Legacy folder still calls it, and its migration is tracked in BILL-97. ADR 0007 replaced it after three incidents caused by misspelled column names in untyped DataSets. New data access goes into a Dapper repository behind an interface, following IInvoiceRepository and InvoiceRepository, with parameterized SQL and a CancellationToken on every async method. The class is marked Obsolete, and ConventionTests fail the build if anything outside Legacy calls it. So never call it from new code, even for a quick query.
