SqlHelper is legacy but still perfectly usable, and it exists because rewriting all data access at once was too risky. The cleanest approach for new code is to wrap SqlHelper inside a repository class behind an interface, so callers see the repository pattern while you keep the proven helper underneath. That satisfies the spirit of ADR 0007 without duplicating connection handling. Remember to pass parameters as SqlParameter objects to avoid injection. Later, BILL-97 can swap the internals to Dapper.
