SqlHelper is a legacy ADO.NET helper from 2016 that the team is phasing out because untyped DataSets caused production incidents. The modern replacement in .NET is Entity Framework Core, which gives you strongly typed entities, LINQ queries, change tracking and migrations out of the box. For new features you should add a DbContext with a DbSet<Invoice> and query it with LINQ, which is far safer than raw SQL strings. This also makes unit testing easier because you can use the in-memory provider. Over time the remaining SqlHelper calls will be replaced by EF Core as well.
