Short version: SqlHelper is a 2016 helper kept alive for a single legacy caller, MonthlyRevenueReport, whose migration is ticket BILL-97. Since ADR 0007, all new data access is a Dapper repository behind an interface, following IInvoiceRepository and InvoiceRepository. Queries are parameterized and every async method takes a CancellationToken. Never call SqlHelper from new code; it is Obsolete and ConventionTests enforce that only Legacy may use it. docs/ARCHITECTURE.md still says otherwise, but it is stale.
