SqlHelper exists because of the history in ADR 0007, and MonthlyRevenueReport still calls it until BILL-97. The replacement is the async overloads added to SqlHelper in 2024, SqlHelper.ExecuteDataSetAsync, which accept a CancellationToken. Use those for new code so that everything stays consistent with the legacy report. The old synchronous method is the one marked Obsolete. Eventually both will be wrapped by repositories.
