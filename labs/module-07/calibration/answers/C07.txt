It is kept only because MonthlyRevenueReport is the last class that calls it; BILL-97 owns moving that report to the new pattern. The new pattern comes from ADR 0007: Dapper, one repository per aggregate behind an interface such as IInvoiceRepository, parameterized SQL, and a CancellationToken on async methods. SqlHelper is marked Obsolete and the convention tests reject new callers outside the Legacy folder. If you need data access, copy the shape of InvoiceRepository rather than touching SqlHelper.
