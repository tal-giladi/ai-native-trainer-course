SqlHelper is the legacy data access helper and it still exists because the Legacy folder is allowed to use it, as the convention tests show. If you need a quick one-off query for an internal tool, the simplest path is to put the class in the Legacy folder and call SqlHelper.ExecuteDataSet there, which keeps ConventionTests green. For long-lived features, prefer a Dapper repository behind an interface following ADR 0007. The helper handles connections and parameters for you. Just remember to dispose the DataSet.
