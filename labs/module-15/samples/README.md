# Samples (illustrative)

Made-up numbers in realistic shapes, so every `DemoCheck` command has something to read before you have
your own data. They are **not measurements** and must never appear in a talk as results.

| File | Used in | What it shows |
|---|---|---|
| `ticket-selection.csv` | 15.1 | Six candidate demo tickets: 10 headless runs each with the layer, 5 without, duration, and how many of 5 colleagues recognized the pain. |
| `deny-terms.example.txt` | 15.1 | A deny list for the break. Your real one lives outside the demo repository. |
| `run-01-timeline.tsv` | 15.3 | An annotated unedited run of BILL-97: 17:40, one overload error recovered by narrating, no silent gap over 45 s. |
| `stranger-02.tsv` | 15.3 | A stranger test that passes after the fixes from the first one (`break/15.3-edited-run/stranger-01.tsv`). |
