# Onboarding (copied from the wiki, 2022)

1. Ask Moshe for access to the Billing database.
2. Clone the repository and open `Billing.sln` in Visual Studio 2019.
3. Run the tests in `Billing.UnitTests`.
4. Read `docs/ARCHITECTURE.md`: all data access goes through `SqlHelper`.
5. Your first ticket will be a small change to the revenue report so you learn the data.
