# Starter pack — v1.3.0

> Part of the practitioner kit. Code, scripts and hooks: MIT (`LICENSE-code`); this README and the exercises: CC BY 4.0 (`LICENSE-docs`).

The public "clone this to start" repository for the workshop and the course: the fictional Contoso Billing application from `brownfield-demo`, on a `workshop` branch with catch-up tags `ws-0-start` to `ws-3-prove`, a setup check for Windows, macOS and Linux, and an offline package feed. The reference layout is the Module 17 starter pack (`labs/module-17/solution/workshop-kit/starter-pack/`).

## Supported

- .NET SDK 8 or newer; Git 2.30 or newer; any coding agent with a command-line tool.
- The latest MINOR version of the kit. Older tags stay available but receive no fixes.
