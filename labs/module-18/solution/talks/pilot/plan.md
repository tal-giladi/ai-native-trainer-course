# Free pilot — plan (illustrative)

> **Illustrative.** A free 60-minute workshop, run exactly like a paid engagement. Company anonymized as "the logistics team"; the real name stays out of every file in `talks/`.

- Host: tech lead of a 14-developer logistics software team, met through a meetup (outside the student's network before 2026-08-20)
- Date: 2026-09-16, 60 minutes, on site; prep call 2026-09-04; follow-up 2026-09-30
- Price: free. Written down so nobody is surprised later: no follow-on work is promised or expected
- Consent: written agreement from the tech lead that the student may publish an anonymized write-up after review; quotes only with the quoted person's approval
- Confidentiality: the student never sees or touches the team's code. Learners search their own code on their own machines; the demo runs on `brownfield-demo`
- Employer: pilot run on a day off; no employer material, time or equipment used (Module 14.4 checklist)

## Prep call (30 minutes, 2026-09-04)

Questions asked about the past, not opinions (Module 1.4): the last agent PR that surprised a reviewer, how rules are found today, who owns the invoicing procedures. Three prior-knowledge notes went into the session plan.

## Session

The Module 16 mini-workshop for C1 *Shadow rule*, stretched to 60 minutes: pre-test (5) → story (3) → worked example on the demo (7) → pairs on three diffs (12) → live step (6) → solo search in own code (17) → reflection (4) → post-test and form (6).

## Measures

- Level 1: relevance rating and the muddiest point
- Level 2: parallel forms A and B, six items, counterbalanced
- Level 3: two-week follow-up to the tech lead: "Did any agent plan name an existing rule? Link or example."

## Definition of done

Feedback read the same day; follow-up sent on day 14; write-up draft sent to the tech lead for review before anything is published.
