# Claim A — a vendor slide (fictional)

> **Fictional exhibit** for the 13.2 exercise. "Nimbus Agent" is an invented product; the slide is written to resemble a common style of vendor claim, not any real company's material.

---

**Nimbus Agent makes developers 55% faster.** *

**Up to 10x on routine work.**

"Our team shipped the whole quarter's roadmap in six weeks." — Engineering Manager, Fortune 500 company

<sub>* In a controlled study, developers using an AI pair programmer completed a coding task 55% faster than developers without one.</sub>

---

Your prospect runs a 15-year-old .NET Framework / SQL Server billing system with stored procedures, 40 developers, and a two-week release train. Their CTO forwards you this slide and asks: "Can we expect 55%?"
